# Shared agent instructions

These instructions apply to work launched with the `ai` workflow.

1. Inspect the repository and its local instructions before editing. Do not assume the stack, commands, or conventions.
2. For non-trivial work, state a short plan before making changes. Keep unrelated working-tree changes intact.
3. Treat `.env`, `.env.*`, `secrets/`, credential files, tokens, sessions, and local overrides as sensitive. Do not read, print, commit, or copy them. Ask when access is essential.
4. Make the smallest change that solves the task. Do not overwrite user work, rewrite history, or perform destructive actions without explicit approval.
5. Run the most relevant verification available and record both what ran and its result. If verification cannot run, say why.
6. For research, save source links, findings, recommendation, open questions, and verification status in the provided note.
